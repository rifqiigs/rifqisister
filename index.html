My Biography

RIFQI GHAIDA SAKHI

Selamat datang di website biografi saya yang dibuat sebagai bagian dari tugas Sistem Terdistribusi Hosting. Saya lahir pada 11 Mei 2004 di Kota Madiun dan memiliki ketertarikan yang besar terhadap dunia game sejak kecil. Bermain game tidak hanya memberikan hiburan, tetapi juga banyak manfaat, seperti meningkatkan kemampuan bahasa Inggris, melatih otak untuk berpikir kritis dalam menyelesaikan masalah, dan bahkan menghasilkan uang saku. Website ini saya buat sebagai sarana untuk belajar lebih dalam mengenai pembuatan website, sekaligus sebagai tugas dalam mata kuliah Sistem Terdistribusi Hosting. Website ini berisi biografi saya dan juga menampilkan beberapa game favorit yang menjadi bagian penting dalam perjalanan hidup saya. Saya menggunakan website lama yang sudah saya buat sebagai bahan untuk dihosting, sehingga dapat mempelajari lebih dalam tentang bagaimana cara kerja sistem hosting dan distribusi dalam pembuatan website ini.
